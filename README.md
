# 🏥 US Healthcare Claims Automation & Validation Engine

A lightweight Python-based audit engine designed to automate the validation of US medical billing codes (`ICD-10`, `CPT`, `HCPCS`, and legacy `ICD-9`). It identifies potential revenue leakage, tracks revenue-at-risk, and routes non-compliant claims for manual RCM review.

---

## 📌 Features
- **Automated Code Classification:** Accurately verifies valid modern billing codes (`ICD-10`, `CPT`, `HCPCS`).
- **Denial Prevention:** Detects deprecated `ICD-9` formats prior to clearinghouse transmission.
- **Financial Risk Metrics:** Computes real-time revenue at risk for unapproved or non-standard claims.
- **Batch Processing:** Iterates through structured claim objects with error handling and summary logs.

---

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Domain Focus:** US Healthcare Revenue Cycle Management (RCM) & Claims Adjudication
